# Snowman-Fear 游戏基本原型设计

> 版本：0.1（原型提案）
> 状态：玩法范围初稿，数值尚待实测
> 目标：先做出一个可反复游玩的单人战斗闭环，再根据试玩结果决定扩展方向。

## 1. 游戏概念

**一句话介绍：** 玩家在雪地中使用雪球枪抵御雪人，可选择白天准备、夜晚防守的昼夜循环，或连续迎战雪人的无尽黑夜。

| 项目 | 当前设想 |
| --- | --- |
| 类型 | 俯视角 2D 生存射击 |
| 平台 | PC |
| 玩家人数 | 原型先实现单人；整体目标最多支持 4 人共同游玩 |
| 游戏模式 | 昼夜循环、无尽黑夜 |
| 目标分辨率 | 1920 × 1080（1080p，16:9） |
| 核心体验 | 持续移动、判断威胁优先级、在包围前清出空间 |
| 题材方向 | 雪夜中的生存与带有轻微荒诞感的雪人敌人 |
| 引擎 | Godot（具体版本待定） |

项目借鉴 Boxhead 的「封闭场地生存、逐波增压、边移动边射击」这一类玩法结构；角色、美术、地图、数值和具体内容应为 Snowman-Fear 自己的设计，不以复刻原作细节为目标。

## 2. 设计目标

1. **上手快：** 进入战斗后无需复杂教学，玩家很快就能移动和发射雪球。
2. **走位有意义：** 雪人从场地边缘接近，停在原地射击会逐渐被包围。
3. **战斗反馈清楚：** 命中、受伤、击杀、配件掉落、抽奖和新波次都要有明确的视觉或声音反馈。
4. **战斗奖励有短期目标：** 击败雪人收集配件，集齐后前往固定抽奖机换取随机物品。
5. **原型范围可控：** 先验证基础枪战、波次节奏和抽奖循环，不先做多人、养成或大量武器。
6. **调参有依据：** 通过短局试玩观察玩家存活时间、命中率和死亡原因，再调整敌人速度、数量和伤害。

## 3. 核心游玩循环

1. 玩家在竞技场中央或预设出生点开始战斗。
2. 雪人从场地边缘的出生点出现，并尝试接近玩家。
3. 玩家用键盘移动并朝移动方向发射雪球，在拉开距离的同时消灭雪人。
4. 被击败的雪人有几率掉落帽子、围巾等配件；玩家走近后自动收集。
5. 每收集三个配件，玩家可前往地图固定位置的抽奖机，按键互动并随机获得一件物品。
6. 按所选模式推进：无尽黑夜在波次间短暂喘息，昼夜循环在夜晚结束后进入白天准备阶段。
7. 玩家生命值归零后结算本局分数、击杀数、到达波次和存活时间。
8. 玩家重新开始，尝试活得更久或打出更高分。

### 模式一：昼夜循环

1. **白天准备：** 场上不生成雪人。玩家可在安全时段收集场地物资、使用固定位置的抽奖机，并布置障碍物和陷阱。
2. **日落预警：** 昼夜切换前显示倒计时和提示，让玩家有时间完成布置并返回防守位置。
3. **夜晚防守：** 雪人从场地边缘来袭，随着夜晚推进逐渐增加压力。玩家使用雪球枪并利用白天布置的障碍和陷阱求生。
4. **日出清场：** 撑到日出即算度过一夜；日出时所有仍存活的雪人自动死亡，不要求玩家逐个击杀。
5. **进入下一天：** 玩家继续收集物资、抽奖和重新布置，之后迎接更难的一夜。循环持续到玩家生命值归零。

昼间拾取物资用于布置障碍和陷阱；雪人掉落的配件仍用于抽奖，两类用途在原型中应清楚区分。日照时间、夜晚时长、物资种类和建造成本均为待调参数。

### 模式二：无尽黑夜

1. 游戏始终处于夜晚，不设置白天阶段和长时间的准备期。
2. 雪人按波次连续来袭；每波清空后仅有短暂间隔，玩家很快就要迎战下一波。
3. 波次推进时逐步提高敌人数量或强度，持续制造更快、更紧张的战斗节奏。
4. 雪人掉落配件，玩家可在战斗间隙或冒险接近抽奖机，消耗三个配件抽取随机物品。
5. 玩家生命值归零后结束本局，记录存活波次、击杀数和分数；模式没有最终通关点。

该模式不提供昼间专属的建造阶段；原型先使用地图预设障碍物。后续是否允许在无尽黑夜中即时布置陷阱，再根据节奏测试决定。

| 对比项 | 昼夜循环 | 无尽黑夜 |
| --- | --- | --- |
| 节奏结构 | 白天准备，夜晚防守，日出后进入下一天 | 短暂波次间隔后立即继续战斗 |
| 雪人出现 | 仅在夜晚出现 | 全程处于夜晚，按波次持续出现 |
| 主要决策 | 如何利用白天资源布置防线、如何撑过整夜 | 如何走位、快速击杀并抓住短暂间隔补给 |
| 建造 | 白天可布置障碍物和陷阱 | 首版不提供专属建造阶段 |
| 难度推进 | 随夜晚/天数逐步增加 | 随波次逐步增加 |
| 结束条件 | 玩家死亡；每次日出代表成功度过一夜 | 玩家死亡；以最高波次和分数为目标 |

### 首个原型的模式范围

建议先用**无尽黑夜的简化版**完成单人战斗闭环：它能先验证移动、雪球枪、雪人追击、配件掉落和抽奖机，不需要同时制作昼夜计时、物资经济和陷阱布置。基础战斗稳定后，再扩展昼夜循环及白天建造。

## 4. 首个可玩原型（MVP）

### 必须包含

- 一张夜晚主题的封闭雪地竞技场，包含少量固定障碍物和一台位置固定的抽奖机。
- 一名玩家：八方向移动、朝向射击、生命值、受伤和死亡。
- 一种基础雪人：从场地边缘生成，追逐玩家，接触时造成伤害；被击败后有几率掉落雪人配件。
- 一种基础武器：雪球枪，可无限发射雪球，不消耗弹药且不需要换弹。
- 配件收集与抽奖：雪人掉落的配件可自动拾取；每三个配件可在抽奖机换取一次随机物品。
- 敌人生成与波次推进：波次清空后进入短暂间隔，再开始下一波。
- 模式范围：只实现无尽黑夜简化版；昼夜循环、昼间物资收集和建造暂不纳入此阶段。
- 最基本的 HUD：生命值、配件数量、当前波次、击杀数和分数。
- 暂停、失败结算和重新开始。
- 击中、受伤、击杀、配件掉落、抽奖结果和波次开始的基础反馈。

### 暂不纳入

- 多人模式（整体目标最多 4 人；首个原型仅单人，具体多人游玩方式待定）、排行榜、账号和云存档。
- 完整昼夜循环、白天资源经济、可布置障碍物和陷阱。
- 多张地图、关卡剧情、角色选择和永久成长。
- 复杂武器库、技能树、制作系统和经济系统。
- 多种敌人、复杂行为树、动态掩体破坏。
- 完整设置菜单、成就系统和最终美术资源。

如果基础玩法尚未证明有趣，应先调整移动、射击手感和波次节奏，而不是用更多系统掩盖问题。

## 5. 操作与战斗规则

| 操作 | 默认输入 | 说明 |
| --- | --- | --- |
| 移动与朝向 | `W` `A` `S` `D` | 单键或组合键实现八方向移动；斜向速度应归一化，角色朝向跟随移动方向 |
| 射击 | `Space` | 按住可连续射击，沿角色当前朝向开火，受射速限制 |
| 使用抽奖机 | `E` | 靠近抽奖机且至少有三个配件时，消耗三个配件并抽取一件随机物品 |
| 暂停 | `Esc` | 暂停战斗并提供继续或重开选项 |

### 初步规则

- 全部战斗操作只使用键盘，不依赖鼠标；射击方向跟随最近一次有效的移动方向，停止移动后保持该方向。
- 玩家和雪人的移动均限制在场地边界内；固定障碍物阻挡双方移动。
- 基础武器为雪球枪，可无限发射雪球，不设弹药数量或换弹流程；雪球命中雪人后造成伤害，且不穿过固定障碍物。
- 雪人以追逐玩家为主，接触后造成伤害；同一只雪人应有明确的攻击间隔，避免每帧重复扣血。
- 被击败的普通雪人有几率掉落配件，例如帽子、围巾、树枝手臂或胡萝卜鼻子；配件种类、掉落概率和掉落数量可调。
- 玩家接触掉落配件时自动拾取；不同种类的配件都计入配件总数，每三个配件可兑换一次抽奖。
- 抽奖机放置在地图的固定位置；玩家靠近后按 `E` 抽奖，每次消耗三个配件并从奖池随机获得一件物品。配件不足时不能抽奖。
- 初版奖池可先包含即时生命恢复和短时间战斗增益；抽奖后奖励立即生效，不增加物品背包。
- 波次结束时保留玩家生命值、配件和已获得的物品效果；是否提供自动治疗留到试玩后决定。
- 无尽黑夜模式波次间只有短暂间隔；昼夜循环模式则以日出作为夜晚结束和下一阶段开始的边界。

## 6. 敌人与波次

### MVP 敌人：普通雪人

- **外观识别：** 由雪球身体、简单面部和明显的移动动作组成；远距离仍能与场地背景区分。
- **行为：** 出生后追逐玩家；遇到障碍时绕行或选择可行路线。
- **攻击：** 靠近玩家后进行近身攻击。
- **死亡：** 受到足够伤害后倒下或散成雪球，并计入击杀与分数；有几率掉落可收集的雪人配件。

首个版本只实现普通雪人。后续可以考虑快跑型、远程投雪球型或耐久型雪人，但应在普通雪人的移动、命中和攻击反馈稳定后再加入。

### 波次节奏

- 无尽黑夜模式：每波由一组普通雪人构成；当前波次清空后短暂间隔，再开始下一波。
- 昼夜循环模式：雪人在夜间持续来袭，日出时强制结束夜晚并清除所有剩余雪人；不要求玩家清空整波才能天亮。
- 波次或夜晚间隔应显示明确的下一波/日出提示。
- 无尽黑夜随波次增加压力；昼夜循环可随夜晚/天数增加压力。初期优先增加敌人数量，再逐步调整生成节奏或敌人耐久。
- 初期避免同时大幅增加数量、速度和伤害，以便定位难度来源。
- 敌人应从玩家视野外或场地边缘生成，避免直接出现在玩家身旁。
- 配件掉落和抽奖机持续提供战斗中的短期奖励目标，不改变波次推进的基本规则。

波次间隔、昼夜时长和敌人规模先作为可调参数，不在本阶段固化为最终平衡值。

## 7. 分数与结算

- 击杀普通雪人获得基础分数；抽奖物品用于本局内的生存或战斗增益，不额外改变分数。
- 本局记录至少包括：总分、击杀数、到达波次和存活时间；昼夜循环模式还可记录成功度过的夜晚数。
- 首个版本不加入连杀倍率、任务目标或局外成长；抽奖仅影响当前局内。
- 失败结算应明确展示本局成绩，并提供「再来一局」操作。

## 8. 画面、声音与界面方向

### 画面

- 使用俯视视角，确保玩家、敌人、弹丸和障碍物容易区分。
- 整体视觉风格偏卡通，以清晰的轮廓、易辨认的表情和适度夸张的动作呈现角色。
- 昼夜循环模式需区分白天与夜晚：白天安全、明亮且适合准备；夜晚使用月光、冷色调和局部灯光营造氛围。雪人怕白天融化，因此仅夜间出现。
- 无尽黑夜模式全程保持雪夜氛围；夜景不能过暗，玩家、雪人、雪球弹道、掉落配件和抽奖机都必须清晰可辨。
- 场地以雪地、冰面或冬季设施为主题，但背景细节不能压过角色和弹道。
- 通过颜色、轮廓和受击闪烁区分玩家与敌人；生命危险时提供清楚但不过度遮挡的提示。
- 抽奖机应有独特轮廓和灯光提示，配件掉落应有明显的出现与拾取反馈。
- 原型阶段可以使用占位图形和简单动画；先验证尺寸、可读性与移动手感。

### 角色美术制作方向

- 角色计划先使用 3D 建模，再离线渲染并导出为 2D 图片资源；游戏本身仍采用 2D 玩法和场景。
- 每个角色至少提供上、右上、右、右下、下、左下、左、左上八个朝向，与八方向移动和攻击对应。
- 有动作的角色可按动作和朝向导出序列帧；原型阶段先保证八方向朝向资源齐全。
- 导出时统一相机角度、角色比例、脚底锚点和光照方向，确保不同朝向及不同角色切换时位置与明暗一致。

### 声音

- 优先补齐雪球发射与命中、受伤、击杀、配件掉落与拾取、抽奖结果、波次开始和失败反馈。
- 声音应帮助玩家判断事件，不要求原型阶段完成完整配乐。

### HUD

- 固定显示生命值、配件数量（每三个可抽奖一次）、击杀数和分数；雪球枪弹药无限，不显示弹药或换弹信息。
- 无尽黑夜模式显示当前波次；昼夜循环模式显示当前阶段、白天/夜晚倒计时和已度过夜晚数。
- 靠近抽奖机时显示键盘互动提示，并让玩家能看见当前配件数和抽奖消耗。
- 波次开始、玩家受伤、拾取配件、抽奖结果和本局结束使用短暂且易读的提示。
- HUD 不应遮挡战斗区域或关键敌人。

## 9. 原型验证标准

完成首个可玩版本后，至少通过以下检查：

- 新玩家不看说明即可理解八方向移动、朝向射击、配件收集和抽奖机互动。
- 玩家能从攻击反馈辨认自己受到伤害，也能确认雪人被击中或击杀。
- 雪人能够按配置概率掉落配件；收集三个配件后可在固定抽奖机成功抽奖并获得随机物品。
- 雪球枪能持续开火且不消耗弹药，也不会出现换弹状态。
- 无尽黑夜模式保持清晰的雪夜氛围，且不妨碍辨认玩家、敌人、弹道、配件和抽奖机。
- 雪人能够稳定生成并追逐玩家；障碍物不会让敌人永久卡死。
- 波次能够按规则开始、清空、间隔并推进，失败后可重新开局。
- 玩家能够通过走位避免被单个雪人持续贴身；停留不动会明显更危险。
- 连续试玩数局后，死亡原因大多能归结为走位、朝向控制或资源管理，而非生成点、碰撞或界面问题。

可记录每局的存活时间、到达波次、击杀数、受伤次数和死亡时屏幕上的敌人数，用于调整难度。具体目标值在第一次内部试玩后再定。

昼夜循环模式扩展完成后，额外验证：

- 白天不生成雪人，玩家可以安全收集物资、抽奖并布置障碍与陷阱。
- 夜晚开始前有清楚的日落预警；雪人只在夜晚来袭。
- 玩家撑到日出后，剩余雪人全部自动死亡并正确进入白天阶段。
- 连续昼夜循环时，玩家状态、配件和建造物的保留规则一致。

## 10. 建议开发顺序

1. **灰盒战斗：** 无尽黑夜场景、玩家八方向移动、键盘朝向控制和无限弹药雪球枪。
2. **敌人闭环：** 普通雪人生成、追逐、受击、死亡、碰撞伤害和配件掉落。
3. **奖励闭环：** 配件自动拾取、固定位置抽奖机、三件配件兑换和随机奖池。
4. **一局完整：** 波次、HUD、分数、失败结算和重开。
5. **手感打磨：** 调整移动速度、射速、命中反馈、掉落概率、抽奖奖励、敌人生成节奏和音效。
6. **试玩迭代：** 记录数据和反馈，确认核心玩法是否值得扩展。
7. **昼夜循环扩展：** 加入白天计时、物资收集、抽奖/准备、障碍与陷阱布置，以及日出清场。
8. **多人扩展：** 单人玩法验证稳定后，再规划并实现最多 4 人共同游玩；具体多人方式另行确定。

## 11. 后续待定事项

- Godot 的具体版本、目标帧率、窗口模式，以及 1080p 下的缩放和其他分辨率适配方式。
- 最多 4 人游玩的具体方式，以及对应的输入设备和多人流程。
- 角色 3D 模型、动画动作列表和八方向资源的最终制作规范。
- 两种模式的最终定位，以及昼夜循环中的白天时长、夜晚时长和雪人生成节奏。
