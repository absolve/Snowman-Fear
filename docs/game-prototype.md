## 1. 游戏概念

**一句话介绍：** 玩家在雪地中使用雪球枪抵御雪人，可选择白天准备、夜晚防守的昼夜循环，或连续迎战雪人的无尽黑夜。

| 项目 | 当前设想 |
| --- | --- |
| 类型 | 俯视角 2D 生存射击 |
| 平台 | PC |
| 玩家人数 | 原型先实现单人；整体目标最多支持 4 人共同游玩 |
| 游戏模式 | 昼夜循环、无尽黑夜 |
| 目标分辨率 | 1920 × 1080（1080p，16:9） |
| 核心体验 | 持续移动、判断威胁优先级、在包围前清出空间 |
| 题材方向 | 雪夜中的生存与带有轻微荒诞感的雪人敌人 |
| 引擎 | Godot（具体版本待定） |

项目借鉴 Boxhead 的「封闭场地生存、逐波增压、边移动边射击」这一类玩法结构；角色、美术、地图、数值和具体内容应为 Snowman-Fear 自己的设计，不以复刻原作细节为目标。

## 2. 设计目标

1. **上手快：** 进入战斗后无需复杂教学，玩家很快就能移动和发射雪球。
2. **走位有意义：** 雪人从场地边缘接近，停在原地射击会逐渐被包围。
3. **战斗反馈清楚：** 命中、受伤、击杀、连杀、配件掉落、抽奖和昼夜切换都要有明确的视觉或声音反馈。
4. **战斗奖励有短期目标：** 击败雪人收集配件，集齐后前往固定抽奖机换取随机物品。
5. **原型范围可控：** 先验证基础枪战、波次节奏和抽奖循环，不先做多人、养成或大量武器。
6. **调参有依据：** 通过短局试玩观察玩家存活时间、命中率和死亡原因，再调整敌人速度、数量和伤害。

## 3. 核心游玩循环

1. 玩家在竞技场中央或预设出生点开始战斗。
2. 雪人从场地边缘的出生点出现，并尝试接近玩家。
3. 玩家用键盘移动并朝移动方向发射雪球，在拉开距离的同时消灭雪人。
4. 被击败的雪人有几率掉落帽子、围巾等配件；玩家走近后自动收集。
5. 每收集三个配件，玩家可前往地图固定位置的抽奖机，按键互动并随机获得一件物品。
6. 按所选模式推进：无尽黑夜在波次间短暂喘息，昼夜循环在夜晚结束后进入白天准备阶段。
7. 玩家生命值归零后结算本局分数、击杀数、最高连杀、成功生存天数和到达的周数。
8. 玩家重新开始，尝试活得更久或打出更高分。

### 模式一：昼夜循环

1. **白天准备：** 场上不生成雪人。玩家可在安全时段收集场地物资、使用固定位置的抽奖机，并布置障碍物和陷阱。
2. **日落预警：** 昼夜切换前显示倒计时和提示，让玩家有时间完成布置并返回防守位置。
3. **夜晚防守：** 雪人从场地边缘来袭，随着夜晚推进逐渐增加压力。玩家使用雪球枪并利用白天布置的障碍和陷阱求生。
4. **日出清场：** 撑到日出即算度过一夜；日出时所有仍存活的雪人自动死亡，不要求玩家逐个击杀。
5. **进入下一天：** 玩家继续收集物资、抽奖和重新布置，之后迎接更难的一夜。循环持续到玩家生命值归零。

昼间拾取物资用于布置障碍和陷阱；雪人掉落的配件仍用于抽奖，两类用途在原型中应清楚区分。日照时间、夜晚时长、物资种类和建造成本均为待调参数。

#### 七日周循环

昼夜循环以七天为一个完整周期。为对应 NPC 的周三、周五和周日，暂定第 1 天为周一、第 3 天为周三、第 5 天为周五、第 7 天为周日。每一天都有安全准备阶段和一夜防守；成功撑到日出才算生存该天。第七天结束后进入下一周，敌人组合按相同日程轮换，但随周数增加压力。

HUD 同时显示当前周数和星期/天数；每次日出后，累计生存天数加一。未撑到日出的当晚不计为完成天数。第七天日出后结算本周并进入下一周，继续使用相同的七日敌人日程。

| 天数 | 夜晚敌人安排 | 当日特点与准备提示 |
| --- | --- | --- |
| 第 1 天（周一） | 普通雪人为主，数量较少 | 入门夜；介绍移动、战斗、拾取和日出规则 |
| 第 2 天（周二） | 普通雪人 + 少量双臂壮雪人 | 首次出现高耐久近战敌人；白天可遇到修补匠 |
| 第 3 天（周三） | 普通雪人 + 投雪球雪人 | 首次加入远程压力；小丑出现 |
| 第 4 天（周四） | 双臂壮雪人 + 投雪球雪人 | 近战阻路与远程压制同时出现；白天可遇到修补匠 |
| 第 5 天（周五） | 自爆雪人 + 普通雪人 | 首次加入爆炸威胁；小丑再次出现 |
| 第 6 天（周六） | 滑冰雪人 + 混合敌人 | 场地干扰增多；滑冰雪人布置的障碍会改变走位路线 |
| 第 7 天（周日） | 多种已出现敌人的混合攻势 | 本周高峰夜；小丑给出已约定的礼物，或恶作剧礼物 |

日程是原型提案，不要求某种敌人只在指定日出现；表中表示该日首次登场或作为主要威胁。下一周不重置玩家的生存总天数，敌人数量和组合强度逐周提升。每夜的具体敌人数、生成节奏和生命值保持为可调参数；避免单纯无限堆叠生命值。

难度按“解锁威胁类型，再逐步增加规模”的顺序推进：第一周让玩家认识敌人招式，之后优先增加敌群规模和混合编组，再小幅提高生成频率。每晚最多安排少数几种主要威胁，巡夜员会提前提示其中一种；不要在同一晚同时大幅提升数量、速度和耐久。

#### 小丑与气球约定

- 小丑在第 3、5、7 天白天出现，玩家可用键盘互动。
- 气球是可携带的消耗物品，可由白天探索、抽奖或其他奖励取得。玩家在周三或周五拜访时，可交给小丑作为周日礼物的约定；若周日当天持有气球，也可在领取礼物前交付。
- 周日结算约定：交过气球则获得一件正面礼物，例如恢复生命、临时战斗增益或额外建造材料；未交气球则收到一件“恶作剧礼物”，内容以短暂负面效果或小规模额外敌袭为主。
- 恶作剧只影响当前局，给出明确预警和反馈，不删除永久进度；礼物种类和概率之后再平衡。
- 气球交付状态持续到周日结算；过期后不跨周保留未兑现的约定。
- 正面礼物和恶作剧礼物在周日白天发放，给玩家留出查看效果和准备防线的时间；不在夜战中强制弹出交易界面。

#### 昼间 NPC 提案

NPC 在白天出现，确保玩家能安全对话和完成交易；每名 NPC 提供不同决策，不应让所有角色都变成同一种商店。

| NPC | 出现时间 | 主要作用 | 原型互动提案 |
| --- | --- | --- | --- |
| 小丑 | 第 3、5、7 天 | 周期性风险/奖励事件 | 接收气球；周日按约定发正面礼物，否则送恶作剧礼物 |
| 修补匠 | 第 2、4、6 天 | 防线建造与维修 | 消耗冰块制作一种障碍或陷阱，或修复已放置设施 |
| 巡夜员 | 每天白天 | 夜晚情报与战术准备 | 提示今晚主要敌人、危险方向或特殊规则；后续可加入可选委托作为奖励来源 |
| 热饮摊贩 | 第 1、4、7 天白天 | 生存恢复的取舍 | 消耗金币购买少量生命恢复或一段短暂抗伤效果；每次出现限购一次 |

首轮实现优先做小丑的气球约定和巡夜员的敌人预告；修补匠、热饮摊贩及其资源交易可后续加入。避免让 NPC 在白天以外要求玩家停下战斗交互。

### 模式二：无尽黑夜

1. 游戏始终处于夜晚，不设置白天阶段和长时间的准备期。
2. 雪人按波次连续来袭；每波清空后仅有短暂间隔，玩家很快就要迎战下一波。
3. 波次推进时逐步提高敌人数量或强度，持续制造更快、更紧张的战斗节奏。
4. 雪人掉落配件，玩家可在战斗间隙或冒险接近抽奖机，消耗三个配件抽取随机物品。
5. 玩家生命值归零后结束本局，记录存活波次、击杀数和分数；模式没有最终通关点。

该模式不提供昼间专属的建造阶段；原型先使用地图预设障碍物。后续是否允许在无尽黑夜中即时布置陷阱，再根据节奏测试决定。

| 对比项 | 昼夜循环 | 无尽黑夜 |
| --- | --- | --- |
| 节奏结构 | 白天准备，夜晚防守，日出后进入下一天 | 短暂波次间隔后立即继续战斗 |
| 雪人出现 | 仅在夜晚出现 | 全程处于夜晚，按波次持续出现 |
| 主要决策 | 如何利用白天资源布置防线、如何撑过整夜 | 如何走位、快速击杀并抓住短暂间隔补给 |
| 建造 | 白天可布置障碍物和陷阱 | 首版不提供专属建造阶段 |
| 难度推进 | 随夜晚/天数逐步增加 | 随波次逐步增加 |
| 结束条件 | 玩家死亡；每次日出代表成功度过一夜 | 玩家死亡；以最高波次和分数为目标 |

### 首个原型的模式范围

建议先用**无尽黑夜的简化版**完成单人战斗闭环：它能先验证移动、雪球枪、雪人追击、配件掉落和抽奖机，不需要同时制作昼夜计时、物资经济和陷阱布置。基础战斗稳定后，再扩展昼夜循环及白天建造。

## 4. 首个可玩原型（MVP）

### 必须包含

- 一张夜晚主题的封闭雪地竞技场，包含少量固定障碍物和一台位置固定的抽奖机。
- 一名玩家：八方向移动、朝向射击、生命值、受伤和死亡。
- 一种基础雪人：从场地边缘生成，追逐玩家，接触时造成伤害；被击败后有几率掉落雪人配件。
- 一种基础武器：雪球枪，可无限发射雪球，不消耗弹药且不需要换弹。
- 配件收集与抽奖：雪人掉落的配件可自动拾取；每三个配件可在抽奖机换取一次随机物品。
- 敌人生成与波次推进：波次清空后进入短暂间隔，再开始下一波。
- 模式范围：只实现无尽黑夜简化版；昼夜循环、昼间物资收集和建造暂不纳入此阶段。
- 最基本的 HUD：生命值、配件数量、当前波次、击杀数和分数。
- 暂停、失败结算和重新开始。
- 击中、受伤、击杀、配件掉落、抽奖结果和波次开始的基础反馈。

### 暂不纳入

- 多人模式（整体目标最多 4 人；首个原型仅单人，具体多人游玩方式待定）、排行榜、账号和云存档。
- 完整昼夜循环、白天资源经济、可布置障碍物和陷阱。
- 多张地图、关卡剧情、角色选择和永久成长。
- 复杂武器库、技能树、制作系统和经济系统。
- 多种敌人、复杂行为树、动态掩体破坏。
- 完整设置菜单、成就系统和最终美术资源。

如果基础玩法尚未证明有趣，应先调整移动、射击手感和波次节奏，而不是用更多系统掩盖问题。

## 5. 操作与战斗规则

| 操作 | 默认输入 | 说明 |
| --- | --- | --- |
| 移动与朝向 | `W` `A` `S` `D` | 单键或组合键实现八方向移动；斜向速度应归一化，角色朝向跟随移动方向 |
| 射击 | `Space` | 按住可连续射击，沿角色当前朝向开火，受射速限制 |
| 切换武器 | `Tab` | 在无限弹药雪球枪和已获得的特殊武器之间切换 |
| 使用抽奖机 | `E` | 靠近抽奖机且至少有三个配件时，消耗三个配件并抽取一件随机物品 |
| 切换快捷物品 | `Q` | 切换当前选中的可使用消耗品 |
| 使用物品 | `F` | 使用或投掷当前选中的消耗品；具体物品可有各自的有效时机 |
| 暂停 | `Esc` | 暂停战斗并提供继续或重开选项 |

### 初步规则

- 全部战斗操作只使用键盘，不依赖鼠标；射击方向跟随最近一次有效的移动方向，停止移动后保持该方向。
- 玩家和雪人的移动均限制在场地边界内；固定障碍物阻挡双方移动。
- 基础武器为雪球枪，可无限发射雪球，不设弹药数量或换弹流程；雪球命中雪人后造成伤害，且不穿过固定障碍物。
- 雪人以追逐玩家为主，接触后造成伤害；同一只雪人应有明确的攻击间隔，避免每帧重复扣血。
- 被击败的普通雪人有几率掉落配件，例如帽子、围巾、树枝手臂或胡萝卜鼻子；配件种类、掉落概率和掉落数量可调。
- 玩家接触掉落配件时自动拾取；不同种类的配件都计入配件总数，每三个配件可兑换一次抽奖。
- 抽奖机放置在地图的固定位置；玩家靠近后按 `E` 抽奖，每次消耗三个配件并从奖池随机获得一件物品。配件不足时不能抽奖。
- 抽奖奖品可包括金币、气球、消耗品、特殊武器或建造材料；多数物品收入背包，生命恢复等奖励可设计为立即生效。
- 玩家可用 `Q` 选择快捷物品、按 `F` 使用；按 `Tab` 切换已获得的武器。交互与战斗均不依赖鼠标。基础雪球枪始终可用且无限弹药，特殊武器作为限时或有限弹药奖励，不取代基础武器。
- 波次结束时保留玩家生命值、配件和已获得的物品效果；是否提供自动治疗留到试玩后决定。
- 无尽黑夜模式波次间只有短暂间隔；昼夜循环模式则以日出作为夜晚结束和下一阶段开始的边界。

### 物品与背包设计

物品按用途分为收集材料/货币、可使用消耗品、特殊武器和可布置设施。昼夜循环中，玩家一局内收集的物品会跨天保留，死亡结算后清空；不做局外永久库存。背包界面以分类列表和数量堆叠为主，战斗常用消耗品放入快捷栏，避免原型阶段实现复杂格子整理。

| 类别 | 物品 | 来源 | 用途与规则 |
| --- | --- | --- | --- |
| 抽奖材料 | 雪人配件：帽子、围巾、纽扣、树枝手臂、胡萝卜鼻子等 | 击败雪人后概率掉落 | 各配件统一计数；每三件在抽奖机兑换一次随机奖品 |
| 委托物品 | 气球 | 白天探索、抽奖或特定奖励 | 交给周三/周五出现的小丑，完成周日礼物约定；约定每周最多完成一次 |
| 货币 | 金币 | 抽奖机奖池 | 与白天 NPC 交易，购买恢复、维修或服务；不用于抽奖，避免货币闭环混淆 |
| 建造材料 | 冰块 | 白天场地拾取或抽奖 | 建造冰墙等障碍、制作陷阱或修复设施；具体配方和携带上限待定 |
| 投掷消耗品 | 鞭炮 | 抽奖、探索或 NPC 奖励 | 朝当前朝向投掷，短暂引爆并对范围内敌人造成伤害；爆炸范围清楚可见 |
| 风险消耗品 | 烟花 | 抽奖或稀有拾取 | 夜晚点燃后从场地边缘额外吸引一小群雪人，作为主动提高风险、争取击杀和掉落的选择；白天无法使用且不消耗 |
| 阶段控制道具 | 尖叫鸡玩具 | 抽奖或小丑礼物 | 仅夜晚可用；触发日出并清除剩余敌人。每夜最多使用一次；白天使用无效且不消耗 |
| 地面陷阱 | 土豆地雷 | 抽奖、修补匠制作或探索 | 放置在地面，敌人进入触发范围后爆炸，对范围内敌人造成伤害；放置时显示危险范围，限制同时存在数量 |
| 特殊武器 | 热射线枪 | 抽奖或稀有奖励 | 沿角色朝向发射高伤害热射线，可短暂穿透多个敌人；持续时间或能量有限，使用后回到雪球枪 |
| 特殊武器 | 雪球加特林 | 抽奖或稀有奖励 | 快速连续发射雪球，单发伤害较低，适合压制成群敌人；弹药或使用时间有限 |
| 特殊武器 | 冰锥发射枪 | 抽奖或稀有奖励 | 发射冰锥，命中敌人或到达一定距离后分裂成多个小冰锥；分裂方向和数量保持清晰可读 |
| 特殊武器 | 加特林烟花 | 抽奖或稀有奖励 | 快速发射多枚烟花弹，对敌群造成范围伤害；弹药稀少且爆炸效果明显，避免与“召敌烟花”混淆 |

#### 可补充的物品提案

- **雪球假人：** 放置后短时间吸引普通近战雪人，为玩家争取转移或布置陷阱的时间；远程敌人仍可能攻击玩家。
- **热可可保温瓶：** 消耗后恢复少量生命；也可作为热饮摊贩的基础商品，与强力的尖叫鸡和武器奖励区分。
- **防滑雪鞋：** 短时间提高移动速度，并减轻滑冰雪人留下的滑面干扰。
- **冰墙工具包：** 消耗一定冰块快速建造一段临时冰墙；墙有耐久、持续时间和场上数量上限，不可封死全部通路。

这些是设计候选，不要求全部进入首个可玩版本。优先实现一个建造材料、一种投掷消耗品和一种特殊武器，验证背包与物品使用流程后再扩充。

## 6. 敌人与波次

### MVP 敌人：普通雪人

- **外观识别：** 由雪球身体、简单面部和明显的移动动作组成；远距离仍能与场地背景区分。
- **行为：** 出生后追逐玩家；遇到障碍时绕行或选择可行路线。
- **攻击：** 靠近玩家后进行近身攻击。
- **死亡：** 受到足够伤害后倒下或散成雪球，并计入击杀与分数；有几率掉落可收集的雪人配件。

首个单人灰盒版本只实现普通雪人。昼夜循环模式的进阶敌人按下表逐步加入，避免基础战斗尚未稳定时同时开发多套行为。

### 昼夜循环敌人阵容

以下敌人属于昼夜循环模式的后续阵容；单人基础原型仍先实现普通雪人。

| 敌人 | 行为与威胁 | 应对与平衡要点 |
| --- | --- | --- |
| 普通雪人 | 直接追逐玩家，接近后近战攻击，是基础数量压力 | 移动和攻击清晰易读；被击败后有几率掉落配件 |
| 双臂壮雪人 | 体型更大、耐久较高，靠近后用双臂挥击造成较高伤害或短暂击退 | 移动较慢，攻击前有明显蓄力/动作提示；优先当作阻路的重型近战敌人 |
| 投雪球雪人 | 保持一定距离，间歇向玩家投掷雪球 | 投掷前显示瞄准/预警轨迹或落点，弹速适中，玩家可通过走位躲避 |
| 自爆雪人 | 追近玩家后进入明显的闪烁或鼓胀预警并自爆；受到致命伤害时也会引爆 | 爆炸有固定范围和短暂预警；可被击败后引爆，但不能无提示瞬间造成伤害；爆炸可伤害附近其他敌人作为战术机会 |
| 滑冰雪人 | 不攻击玩家，以滑行方式穿越场地并沿途放置干扰物 | 干扰物可以是短暂存在的滑面、雪球堆或小路障，改变移动路线但不封死通道；雪人本体可被击败 |

自爆雪人的规则要让玩家一眼能判断当前处于“追近”还是“即将爆炸”；爆炸伤害不应因同时满足“靠近”和“被击败”而重复结算。滑冰雪人的干扰物需要有明显外观和持续时间，并限制场上数量，避免永久堵塞地图。

### 波次节奏

- 无尽黑夜模式：每波由一组普通雪人构成；当前波次清空后短暂间隔，再开始下一波。
- 昼夜循环模式：雪人在夜间持续来袭，日出时强制结束夜晚并清除所有剩余雪人；不要求玩家清空整波才能天亮。
- 昼夜循环按七日表安排敌人首次登场和主要组合；周数增加时增强敌群，而不是突然加入大量新机制。
- 波次或夜晚间隔应显示明确的下一波/日出提示。
- 无尽黑夜随波次增加压力；昼夜循环可随夜晚/天数增加压力。初期优先增加敌人数量，再逐步调整生成节奏或敌人耐久。
- 初期避免同时大幅增加数量、速度和伤害，以便定位难度来源。
- 敌人应从玩家视野外或场地边缘生成，避免直接出现在玩家身旁。
- 配件掉落和抽奖机持续提供战斗中的短期奖励目标，不改变波次推进的基本规则。

波次间隔、昼夜时长和敌人规模先作为可调参数，不在本阶段固化为最终平衡值。

## 7. 分数与结算

- 昼夜循环的主要成绩由总分和成功生存天数构成；同时记录到达周数、当前天数、击杀数、各类敌人击杀数及最长连杀。
- 每种敌人有基础击杀分值；重型、远程和自爆类威胁可有较高基础分，具体分值待试玩平衡。
- 连续击杀会累积连杀数并提高分数倍率。每次击杀刷新连杀倒计时；倒计时结束未击杀则连杀归零。倍率按连杀档位递增并设置上限，避免无限增长。
- 可先用以下倍率档位做灰盒测试，后续根据平均击杀节奏调整：1–2 连杀为 ×1.0，3–4 为 ×1.25，5–7 为 ×1.5，8–11 为 ×2.0，12 连杀及以上为 ×2.5。连杀间隔建议先设为 5 秒。
- 连杀只在夜战中累计，日出时结算并清零；白天 NPC 交易、抽奖和环境事件不增加击杀连杀。
- 由玩家布置的陷阱击杀可计入分数；日出自动清除的雪人不计玩家击杀、不掉落配件，也不延续连杀，避免等待日出刷奖励。
- 小丑的礼物、NPC 服务和抽奖奖励用于本局内的生存或战斗增益，不直接增加击杀分数。
- 无尽黑夜记录总分、击杀数、最高连杀、到达波次和存活时间；昼夜循环记录总分、击杀数、最高连杀、成功生存天数和到达周数。
- 失败结算应明确展示本局成绩，并提供「再来一局」操作。
- 分数倍率阈值、连杀计时长度、各敌人基础分值及排行榜/纪录保存方式留待后续确定。

## 8. 画面、声音与界面方向

### 画面

- 使用俯视视角，确保玩家、敌人、弹丸和障碍物容易区分。
- 整体视觉风格偏卡通，以清晰的轮廓、易辨认的表情和适度夸张的动作呈现角色。
- 昼夜循环模式需区分白天与夜晚：白天安全、明亮且适合准备；夜晚使用月光、冷色调和局部灯光营造氛围。雪人怕白天融化，因此仅夜间出现。
- 无尽黑夜模式全程保持雪夜氛围；夜景不能过暗，玩家、雪人、雪球弹道、掉落配件和抽奖机都必须清晰可辨。
- 场地以雪地、冰面或冬季设施为主题，但背景细节不能压过角色和弹道。
- 通过颜色、轮廓和受击闪烁区分玩家与敌人；生命危险时提供清楚但不过度遮挡的提示。
- 抽奖机应有独特轮廓和灯光提示，配件掉落应有明显的出现与拾取反馈。
- 原型阶段可以使用占位图形和简单动画；先验证尺寸、可读性与移动手感。

### 角色美术制作方向

- 角色计划先使用 3D 建模，再离线渲染并导出为 2D 图片资源；游戏本身仍采用 2D 玩法和场景。
- 每个角色至少提供上、右上、右、右下、下、左下、左、左上八个朝向，与八方向移动和攻击对应。
- 有动作的角色可按动作和朝向导出序列帧；原型阶段先保证八方向朝向资源齐全。
- 导出时统一相机角度、角色比例、脚底锚点和光照方向，确保不同朝向及不同角色切换时位置与明暗一致。

### 声音

- 优先补齐雪球发射与命中、受伤、击杀、配件掉落与拾取、抽奖结果、波次开始和失败反馈。
- 声音应帮助玩家判断事件，不要求原型阶段完成完整配乐。

### HUD

- 固定显示生命值、配件数量（每三个可抽奖一次）、击杀数和分数；雪球枪弹药无限，不显示弹药或换弹信息。
- 无尽黑夜模式显示当前波次；昼夜循环模式显示当前周数、星期/天数、当前阶段、白天/夜晚倒计时和已生存天数。
- 夜战显示当前连杀数、倍率和剩余连杀时间；连杀接近中断时给予醒目但不遮挡战斗的提示。
- 显示金币、冰块等主要材料数量、当前武器及其剩余弹药/持续时间，以及当前快捷消耗品数量。
- NPC 在场时显示姓名、可互动提示和简短交易/约定状态；周日提示小丑礼物结果及气球约定状态。
- 靠近抽奖机时显示键盘互动提示，并让玩家能看见当前配件数和抽奖消耗。
- 日落预警、日出清场、玩家受伤、连杀升级/中断、拾取配件、抽奖结果、NPC 礼物和本局结束使用短暂且易读的提示。
- HUD 不应遮挡战斗区域或关键敌人。

## 9. 原型验证标准

完成首个可玩版本后，至少通过以下检查：

- 新玩家不看说明即可理解八方向移动、朝向射击、配件收集和抽奖机互动。
- 玩家能从攻击反馈辨认自己受到伤害，也能确认雪人被击中或击杀。
- 雪人能够按配置概率掉落配件；收集三个配件后可在固定抽奖机成功抽奖并获得随机物品。
- 雪球枪能持续开火且不消耗弹药，也不会出现换弹状态。
- 无尽黑夜模式保持清晰的雪夜氛围，且不妨碍辨认玩家、敌人、弹道、配件和抽奖机。
- 雪人能够稳定生成并追逐玩家；障碍物不会让敌人永久卡死。
- 波次能够按规则开始、清空、间隔并推进，失败后可重新开局。
- 玩家能够通过走位避免被单个雪人持续贴身；停留不动会明显更危险。
- 连续试玩数局后，死亡原因大多能归结为走位、朝向控制或资源管理，而非生成点、碰撞或界面问题。

可记录每局的存活时间、到达波次、击杀数、受伤次数和死亡时屏幕上的敌人数，用于调整难度。具体目标值在第一次内部试玩后再定。

昼夜循环模式扩展完成后，额外验证：

- 白天不生成雪人，玩家可以安全收集物资、抽奖并布置障碍与陷阱。
- 夜晚开始前有清楚的日落预警；雪人只在夜晚来袭。
- 玩家撑到日出后，剩余雪人全部自动死亡并正确进入白天阶段。
- 连续昼夜循环时，玩家状态、配件和建造物的保留规则一致。
- 七天按固定次序轮换；第七天日出后正确进入下一周，生存天数与周数统计准确。
- 各敌人按日程登场，攻击预警可读且不会出现重复伤害或不可躲避的攻击。
- 连续击杀会按规则刷新计时并提升倍率；超时和日出会正确清除连杀。
- 玩家可在周三或周五向小丑交付气球，并在周日收到对应礼物；未交付时只触发已说明的恶作剧。
- NPC 只在白天安全交互；修补、预告和恢复服务的效果、成本及限购次数清晰。
- 配件、气球、金币和冰块用途易于区分；NPC 交易会正确扣除金币或建造材料。
- 鞭炮、烟花、尖叫鸡、地雷和特殊武器均有清楚的使用反馈及数量/持续时间提示。
- 烟花只在夜晚召来额外敌人；尖叫鸡只在夜晚提前日出，白天使用不消耗且不产生效果。
- 加特林烟花作为攻击武器与召敌用烟花可以从图标、颜色和效果上明确区分。

## 10. 建议开发顺序

1. **灰盒战斗：** 无尽黑夜场景、玩家八方向移动、键盘朝向控制和无限弹药雪球枪。
2. **敌人闭环：** 普通雪人生成、追逐、受击、死亡、碰撞伤害和配件掉落。
3. **奖励闭环：** 配件自动拾取、固定位置抽奖机、三件配件兑换和随机奖池。
4. **一局完整：** 波次、HUD、分数、失败结算和重开。
5. **手感打磨：** 调整移动速度、射速、命中反馈、掉落概率、抽奖奖励、敌人生成节奏和音效。
6. **试玩迭代：** 记录数据和反馈，确认核心玩法是否值得扩展。
7. **昼夜循环核心：** 加入昼夜阶段、七日敌人日程、日出清场、生存天数统计和连杀计分。
8. **昼间准备与 NPC：** 加入物资收集、障碍/陷阱布置、巡夜员情报和小丑气球约定；再按优先级加入修补匠与热饮摊贩。
9. **物品与武器扩展：** 加入背包分类、金币交易、冰块建造、快捷消耗品和特殊武器，再逐步扩展奖池。
10. **多人扩展：** 单人玩法验证稳定后，再规划并实现最多 4 人共同游玩；具体多人方式另行确定。

## 11. 后续待定事项

- Godot 的具体版本、目标帧率、窗口模式，以及 1080p 下的缩放和其他分辨率适配方式。
- 最多 4 人游玩的具体方式，以及对应的输入设备和多人流程。
- 角色 3D 模型、动画动作列表和八方向资源的最终制作规范。
- 昼夜循环中的白天/夜晚时长、雪人生成节奏，以及七日后周数的难度成长幅度。
- 白天可收集的建造物资、障碍物与陷阱种类、放置规则和建造成本。
- 各类敌人的基础分值、连杀间隔、倍率档位与倍率上限。
- 气球的来源与稀有度、小丑礼物池，以及恶作剧效果的种类和概率。
- 修补匠、巡夜员和热饮摊贩的最终出场频率、交易成本及效果。
- 物品背包容量、快捷栏数量、特殊武器弹药/持续时间，以及各消耗品的持有上限。
- 抽奖奖池的物品种类、效果、权重和金币/冰块的产出数量。
- 波次生存是否另做限时或关卡模式。
- 雪人配件的掉落概率、各配件外观，以及配件是否有稀有度。
- 是否允许抽奖机在一局中无限次使用（每次仍消耗三个配件）。
- 玩家是否能在波次间恢复生命。
- 是否加入第二种敌人、第二种武器或更多地图互动。

这些事项应结合首个可玩版本和实际试玩再决定，不作为当前原型的前置条件。
